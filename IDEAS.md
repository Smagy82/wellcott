## Конкурентный ландшафт (кратко)
- Веб-директории (freeclinics.us, freeclinicdirectory.org, NAFC, HealthCare.gov) — большие базы, но это САЙТЫ, часто устаревшие/громоздкие.
- Приложения-локаторы (Access2Day и пр.) — примитивные, привязаны к одной сети клиник, слабый UX.
- Полноценного современного НАЦИОНАЛЬНОГО мобильного приложения под незастрахованных с офлайн-базой по сути НЕТ. Это окно Wellcott.

## СТОМАТОЛОГИЯ — ИСТОЧНИКИ ДАННЫХ И АРХИТЕКТУРА (проработка 13.07.2026)

⚠️ ГЛАВНЫЙ ВЫВОД: единого API «стоматологии для незастрахованных» НЕ СУЩЕСТВУЕТ.
База собирается слоями, как HRSA. 3 из 4 слоёв — бесплатные и public domain.
Это НЕ спринт до релиза. Сейчас делаем только Слой 4 (статический JSON).

### Слой 1 — dental-флаг на существующей базе HRSA (10 429)

Подтверждено 10.07.2026: в site-данных HRSA, которые дёргает build-clinic-db.mjs,
типа услуг нет. Два обхода:

**(А) findahealthcenter.hrsa.gov — РАЗВЕДКА, делать первой.**
В UI локатора ЕСТЬ фильтр по услугам (Dental / Behavioral / Vision).
Значит site-level данные о dental у HRSA существуют — просто в другом эндпоинте.
Задача на ~20 минут: открыть локатор → DevTools → Network → поставить галку Dental →
посмотреть XHR-запрос. Если там JSON-эндпоинт по ZIP/lat-lng — джекпот:
прогоняем по всем ZIP и получаем `has_dental` НА КОНКРЕТНЫЙ АДРЕС.
→ Если эндпоинта нет / он закрыт — переходим к (Б).

**(Б) UDS (Uniform Data System) — запасной путь.**
Грантополучатели ежегодно отчитываются: services provided, staffing, utilization.
Table 5 (Staffing & Utilization) содержит Dental FTE / dental visits.
Dental FTE > 0 → у ОРГАНИЗАЦИИ есть стоматология.
Мапить BHCMISID грантополучателя → его service delivery sites.
Скачивается XLSX/CSV с data.hrsa.gov (Data Downloads / Electronic Reading Room), бесплатно.
⚠️ МИНУС: флаг на уровне ОРГАНИЗАЦИИ, не конкретного адреса.
Формулировка в UI обязана быть честной:
"This health center organization provides dental care — call this location to confirm."
НЕЛЬЗЯ писать "Dental available here" — это будет враньё для части сайтов.

### Слой 2 — дентальные школы (самая недооценённая ценность)

Клиники при dental schools: 40–70% ниже обычных цен, лечат студенты под надзором преподавателей.
- ~70 CODA-аккредитованных dental schools
- ~250–300 программ dental hygiene (чистки/профилактика почти даром)
API нет, но СПИСОК КОНЕЧНЫЙ → разовый ручной сбор / скрейп в CSV. Работа на пару вечеров.
Критично для штатов, где Medicaid для взрослых = emergency-only (TX, FL, AZ, NV, GA):
там dental school часто ЕДИНСТВЕННЫЙ реальный вариант.
⚠️ ЧЕСТНОСТЬ: dental school = ДЕШЕВЛЕ, но НЕ бесплатно и ДОЛГО (студенты, много визитов,
запись за недели). Писать прямо, иначе юзер разочаруется и удалит приложение.

### Слой 3 — благотворительные каналы

- **Dental Lifeline Network / Donated Dental Services** — бесплатное КОМПЛЕКСНОЕ лечение,
  но жёсткий eligibility: пожилые / инвалиды / тяжелобольные. → отдельный блок в UI,
  НЕ смешивать с общим списком клиник (иначе ложные ожидания у всех остальных).
- **Mission of Mercy (MOM)** — бесплатные события от штатных dental associations.
  ⚠️ Это ДАТЫ, а не адреса. Офлайн-база не подходит → отдельная сущность в Supabase
  с онлайн-обновлением. Протухшее событие хуже отсутствия события.
- **NAFC / free clinics** — часть с dental-тегом. Тот же второй источник, что и в п.1/п.4 выше.

### Слой 4 — ГОСПРОГРАММЫ, статический JSON (делать ПЕРВЫМ — дёшево и ценно)

Формат: как assets/financial-help.json. Не требует ETL, не трогает clinics-v*.db,
ложится в существующий Help-экран. ~50 записей + логика по штату пользователя.

Главный факт, который должен усвоить юзер: **ДЕТИ — ВЕЗДЕ, ВЗРОСЛЫЕ — КАК ПОВЕЗЁТ.**

- **EPSDT**: дети до 21 обязаны получать комплексную стоматологию по федеральному закону
  во ВСЕХ штатах. Универсально, можно писать без оговорок по штатам.
- **Взрослые**: классификация HRSA/CHCS —
  - Emergency-Only: только снятие боли (на практике = удаление зуба)
  - Limited: <100 процедур по ADA, годовой кап ≤ $1000
  - Extensive: >100 процедур, годовой кап ≥ $1000
  Цифры плавают год к году, источники в вебе противоречат друг другу.
  → Каноничный источник: **CareQuest Institute** (на него ссылается ADA). Не блоги, не агрегаторы.
  Alabama — единственный штат без adult dental вообще (кроме беременных).
- Плюс: CHIP, IHS (коренные американцы), VA (ветераны), Ryan White.
- ⚠️ ОБЯЗАТЕЛЬНАЯ СНОСКА: даже при наличии Medicaid только ~20–30% дантистов его принимают.
  Без этой сноски юзер упрётся в стену и решит, что приложение соврало.

### Часы работы стоматологий

Тот же паттерн Google Places (Text Search → Place Details).
⚠️ ДЕНЬГИ: ~$0.04/точка. Сначала собрать адреса бесплатно, обогащать ПОТОМ и ВЫБОРОЧНО.

### Терминология — красная зона (нарушение = отзыв из стора / потеря партнёрств)

- FQHC dental = **sliding scale**, НЕ бесплатно. Бейдж `FREE` вешать нельзя.
- Dental school = **дешевле**, НЕ бесплатно, и ДОЛГО. Писать прямо.
- Слово `coverage` / `covered` в контенте ЗАПРЕЩЕНО (см. AGENTS.md).
  Для Medicaid-блока нужна замена, например:
  "What your state Medicaid pays for" / "Dental benefits for adults in your state".

## РОСТ И ВИРУСНОСТЬ (после релиза, из анализа болей аудитории 10.07.2026)

Данные о болях (исследования 2025-2026):
- 94% отказов в госпитальной финпомощи — из-за неверного/устаревшего proof of income. Люди теряют право на бесплатную помощь на бумажке.
- Транспорт до клиники — критический недооценённый барьер для малоимущих с хроническими болезнями.
- 41% незастрахованных откладывают помощь из страха цены (вдвое чаще застрахованных) → ценовой экран бьёт точно в цель.
- Меддолг и ментальное здоровье без денег — растущие боли.

Идеи (приоритет):
1. [ ] Кнопка "Поделиться" клиникой/приложением одним тапом. ВИРУСНЫЙ ДВИЖОК №1.
   Сарафан — главный канал для этой аудитории (она часто вне обычных медиа). Делать ПЕРВОЙ после релиза.
2. [ ] Транспорт до клиники — в деталях кнопка "как доехать без машины" (211 помогает с транспортом, общественный транспорт).
3. [ ] Гайд "как подтвердить доход" (self-attestation если платят наличными / нет pay stub). Спасает льготный тариф — 94% отказов из-за этого.
       ⚠️ ЧАСТИЧНО ЗАКРЫТ экраном Sliding Scale (блок "How to get the discount" + предупреждение про pay stub).
       Остаётся отдельная тема: self-attestation для тех, кому платят наличными (нет официального pay stub).
4. [ ] Ментальное здоровье — отдельная подборка (труднее всего найти без денег).

Каналы роста (стратегия, не фичи):
- Word-of-mouth через точки скопления: soup kitchens, церкви, библиотеки, community-центры, Salvation Army. Раздать QR-код приложения. Главный дешёвый канал.

## РАЗВЕДКА ДАННЫХ — ИТОГИ (13.07.2026)

### SAMHSA findtreatment.gov — ЗЕЛЁНЫЙ ✅

- **12,427 MH facilities** по всей стране (запрошено limitType=0 по всем 50 штатам + DC).
- **Public domain** (17 U.S.C. § 105, SAMHSA / HHS). Офлайн-кэш и бандлинг в приложении разрешены.
- **Bulk = 50 запросов**: `limitType=0&limitValue={stateId}&sType=mh&pageSize=2000` — функционально bulk.
- Параметры подтверждены: `sAddr={lat},{lng}` (широта первой!), `limitType=2` = радиус в метрах.
  Полная документация: `scripts/probe/samhsa-api-notes.md`.
- Sliding scale детектируется: `services[].f2==='PYAS' && f3.includes('Sliding fee scale')`.
- **Блокер**: нужен API-доступ по форме (форма на findtreatment.gov) + статический IP (VPS).
- **Реализация — ПОСЛЕ релиза в сторы.** Отдельный MH-экран, не смешивать с FQHC.

### Dental через HRSA/UDS — ТУПИК, ЗАКРЫТО ⛔

- `BHCMISID` отсутствует в HRSA HDW API (подтверждено developer guide).
- `BCD_HC.zip` (crosswalk `HCC_FCT_ID → BHCMISID`) → 404, не существует публично.
- UDS bulk download (Table 3A / Table 5) → 403 (bphc.hrsa.gov, требует логин).
- BPHC profile pages → 403 CDN (Akamai блокирует ботов).
- Детерминированного join `clinics.id → BHCMISID` нет. Адресный fuzzy match — отклонён.
- **Скрейпинг сайтов клиник — ОТКЛОНЁН, ПОПЫТАН И ОТКАЧЕН (14.07.2026)**:
  Был написан `build-dental-flags.mjs` + `dental-signals.mjs`, прогнан по ~2261 уникальным доменам.
  Результат: strong=5415 (52%), medium=64, none=1030, unknown=3920.
  **Критический провал**: сигнал на уровне ОРГАНИЗАЦИИ, не локации.
  `arcare.net` (82 адреса) → все 82 получили `strong`, хотя дантист есть не во всех.
  Кавэйт "call to confirm" не спасает: люди доверяют фильтру, который мы поставили.
  Человек с зубной болью фильтрует, едет 40 миль → слышит "мы этим не занимаемся" →
  убитое доверие, плохой отзыв в сторе, репутационный ущерб.
  Весь dental-UI (чип, бейдж, колонка dental_signal) откачен в том же коммите.
  Урок: эвристика "слово на сайте" = ложные срабатывания = ХУЖЕ отсутствия фичи.

## ОТКРЫТЫЕ ВОПРОСЫ ПО SLIDING SCALE (из обсуждения 12.07.2026)
- Nominal charge: при ≤100% FPG клиника ВПРАВЕ брать символическую плату ($5–20).
  Поэтому НЕЛЬЗЯ обещать "бесплатно" — только "often free or a small flat fee".
