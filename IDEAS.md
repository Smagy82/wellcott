# Wellcott — бэклог идей (конкурентный анализ)

Отдельно от ROADMAP.md (там — блокеры релиза). Здесь — фичи на проработку ПОСЛЕ базового релиза.
⚠️ Приоритет №1 — выйти в сторы. Не давать фича-крипу отложить релиз.

## Конкурентный ландшафт (кратко)
- Веб-директории (freeclinics.us, freeclinicdirectory.org, NAFC, HealthCare.gov) — большие базы, но это САЙТЫ, часто устаревшие/громоздкие.
- Приложения-локаторы (Access2Day и пр.) — примитивные, привязаны к одной сети клиник, слабый UX.
- Полноценного современного НАЦИОНАЛЬНОГО мобильного приложения под незастрахованных с офлайн-базой по сути НЕТ. Это окно Wellcott.

## ДЕЛАТЬ — высокая ценность, низкий риск
1. [ ] Фильтр по типу услуги (dental / mental health / primary care / pharmacy / women's health / vision).
       Самый частый запрос у незастрахованных; стоматология и mental health — сложнее всего найти.
       БЛОКЕР: проверить, есть ли в HRSA-данных (assets/clinics-v3.db) поле с типом услуг. Если есть — флагманская фича.
       Это главное отличие от "просто списка на карте".
2. [ ] Чек-лист "Что взять на первый визит": ID, proof of income (pay stub), proof of address, список лекарств.
       Без proof of income выставят полный тариф вместо льготного. Статичный экран, ноль данных, ноль риска. ~20 мин.
3. [ ] Экстренный дисклеймер "911 / это НЕ для неотложной помощи" — маленькая плашка.
       Нужна и юзеру, и для ревью сторов (медкатегория). Встроить в About-экран.

## ПОДУМАТЬ — ценно, зависит от данных
4. [ ] Бейдж "Free" vs "Sliding scale" — если в HRSA-данных различима стоимость.
       Люди хотят знать "сколько будет стоить ДО входа" (прямой инсайт freeclinics.us).
5. [ ] Ссылки на смежные ресурсы: Medicaid / ACA marketplace / телемедицина (частично уже в Help).

## НЕ ДЕЛАТЬ (осознанно отклонено)
- Рейтинги/отзывы Google — для FQHC контрпродуктивно (мало отзывов, заниженные оценки отпугивают от нужной помощи). Плюс Enterprise SKU = деньги.
- Community-форумы — модерация, токсичность, не миссия.
- Запись на приём / booking — EHR-территория, HIPAA, партнёрский трек с FQHC.
- Сбор SSN/дохода/форм для регистрации на программы — HIPAA-ад, только через аккредитованного партнёра (FQHC/НКО). См. ROADMAP "путь к гос-деньгам".
- Medical tourism — не наша аудитория.
