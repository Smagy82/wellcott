Отдельно от ROADMAP.md (там — блокеры релиза). Здесь — фичи на проработку ПОСЛЕ базового релиза.

## Конкурентный ландшафт (кратко)
- Веб-директории (freeclinics.us, freeclinicdirectory.org, NAFC, HealthCare.gov) — большие базы, но это САЙТЫ, часто устаревшие/громоздкие.
- Приложения-локаторы (Access2Day и пр.) — примитивные, привязаны к одной сети клиник, слабый UX.
- Полноценного современного НАЦИОНАЛЬНОГО мобильного приложения под незастрахованных с офлайн-базой по сути НЕТ. Это окно Wellcott.

## ДЕЛАТЬ — высокая ценность, низкий риск
1. [ ] Фильтр по типу услуги (dental / mental health / primary care / pharmacy / women's health / vision).
       Самый частый запрос у незастрахованных; стоматология и mental health — сложнее всего найти.
       ⚠️ ПРОВЕРЕНО 10.07.2026: типа услуг в HRSA-базе НЕТ (все клиники = обобщённый Health Center Site).
       Фильтр по услугам невозможен на текущих данных. Требует внешнего источника:
       (а) HRSA UDS-таблицы (разбивка по услугам, другой формат — отдельный ETL);
       (б) второй источник NAFC/freeclinics.us (есть теги dental/mental).
       → Крупная задача на ПОСЛЕ релиза, не быстрая.

   ⚠️ ВАЖНО про источники данных и бейджи:
   NAFC / freeclinics.us — второй источник данных = НАСТОЯЩИЕ бесплатные клиники (free & charitable, ~1400).
   ВАЖНО: текущая база (HRSA/FQHC) — это sliding-scale, НЕ бесплатные. Для низкого дохода часто $0,

   после интеграции NAFC как второго источника (отдельный ETL, после релиза).

## ПОДУМАТЬ — ценно, зависит от данных
4. [ ] Бейдж "Free" vs "Sliding scale" — фильтр/бейджи по стоимости приёма.
       Люди хотят знать "сколько будет стоить ДО входа" (прямой инсайт freeclinics.us).
       ✅ ДАННЫЕ ЕСТЬ: accepts_uninsured + sliding_scale заполнены у всех 10429, уже частично в UI.
       Можно сделать бейджи/фильтр НЕМЕДЛЕННО без доп. источников и денег. Быстрая фича.
5. [ ] Ссылки на смежные ресурсы: Medicaid / ACA marketplace / телемедицина (частично уже в Help).
6. [ ] AI-помощник по приложению (НЕ медицинский чат).
       Идея: бот, помогающий навигировать ресурсы приложения (как найти стоматологию, что взять
       на визит, объяснить sliding scale). Работает ТОЛЬКО с контентом приложения (клиники, Help,
       чек-лист, цены). Есть OpenAI API-ключ.
       ⚠️ РИСКИ (обязательно учесть):
       - НИКОГДА не давать медсоветы/диагнозы/рекомендации лекарств — только навигация по ресурсам.
         На любой медвопрос: "не могу дать медсовет, обратитесь к врачу / позвоните в клинику".
       - Медкатегория сторов = придирчивый ревью AI. Нужны жёсткие ограничения и дисклеймеры.
       - Галлюцинации: бот НЕ должен выдумывать клиники/цены/программы. Нужен RAG поверх своей базы,
         а не свободная генерация. Это серьёзная инженерия, не "подключить API".
       - Стоимость запросов vs аудитория без денег — продумать лимиты.
       - НЕ БЛОКЕР релиза. Только ПОСЛЕ выхода в сторы. Не давать отложить релиз (см. риск №1 фича-крипа).

7. [ ] Синк чеклиста First Visit в Supabase — сейчас прогресс живёт только в AsyncStorage.
       При залогиненном пользователе — бекап в облако (таблица `visit_prep`, RLS).
       Полезно при смене устройства. Сложность: низкая. Зависит от: Supabase account.
8. [ ] OCR документов на приёме — фото income-doc / proof-of-address → извлечение данных.
       Технология: expo-camera + on-device MLKit (не Google Vision — данные не должны уходить в облако).
       ⚠️ Отправка на сервер — HIPAA-территория. Только on-device OCR рассматривать.
9. [ ] FHIR / EHR интеграция — SMART on FHIR (21st Century Cures Act, обязателен для крупных EHR).
       Позволяет предзаполнять medications/allergies из EHR пациента с его согласия.
       Зависит от: партнёрства с FQHC. Сложность: высокая. Долгосрочный вектор.

## НЕ ДЕЛАТЬ (осознанно отклонено)
- Рейтинги/отзывы Google — для FQHC контрпродуктивно (мало отзывов, заниженные оценки отпугивают от нужной помощи). Плюс Enterprise SKU = деньги.
- Community-форумы — модерация, токсичность, не миссия.
- Запись на приём / booking — EHR-территория, HIPAA, партнёрский трек с FQHC.
- Сбор SSN/дохода/форм для регистрации на программы — HIPAA-ад, только через аккредитованного партнёра (FQHC/НКО). См. ROADMAP "путь к гос-деньгам".
- Medical tourism — не наша аудитория.

## РОСТ И ВИРУСНОСТЬ (после релиза, из анализа болей аудитории 10.07.2026)

Данные о болях (исследования 2025-2026):
- 94% отказов в госпитальной финпомощи — из-за неверного/устаревшего proof of income. Люди теряют право на бесплатную помощь на бумажке.
- Транспорт до клиники — критический недооценённый барьер для малоимущих с хроническими болезнями.
- 41% незастрахованных откладывают помощь из страха цены (вдвое чаще застрахованных) → ценовой экран бьёт точно в цель.
- Меддолг и ментальное здоровье без денег — растущие боли.

Идеи (приоритет):
1. [ ] Кнопка "Поделиться" клиникой/приложением одним тапом. ВИРУСНЫЙ ДВИЖОК №1.
   Сарафан — главный канал для этой аудитории (она часто вне обычных медиа). Делать ПЕРВОЙ после релиза.
2. [ ] Транспорт до клиники — в деталях кнопка "как доехать без машины" (211 помогает с транспортом, общественный транспорт).
3. [ ] Гайд "как подтвердить доход" (self-attestation если платят наличными / нет pay stub). Спасает льготный тариф — 94% отказов из-за этого.
       ⚠️ ЧАСТИЧНО ЗАКРЫТ экраном Sliding Scale (блок "How to get the discount" + предупреждение про pay stub).
       Остаётся отдельная тема: self-attestation для тех, кому платят наличными (нет официального pay stub).
4. [ ] Ментальное здоровье — отдельная подборка (труднее всего найти без денег).

Каналы роста (стратегия, не фичи):
- Word-of-mouth через точки скопления: soup kitchens, церкви, библиотеки, community-центры, Salvation Army. Раздать QR-код приложения. Главный дешёвый канал.
- Микро-инфлюенсеры / локальные community-лидеры (доверие > охват звёзд).
- TikTok для НКО (алгоритм по вовлечённости) — образовательный контент про доступную помощь.
- Вирусность нельзя инженерить сверху — дать людям простой повод поделиться (кнопка share) + эмоциональные истории конкретных людей.

## ОТКРЫТЫЕ ВОПРОСЫ ПО GFE (из реализации 12.07.2026)
- Текущая реализация — только для uninsured/self-pay (No Surprises Act scope). Insured-пациенты
  получают AOB (Advanced Explanation of Benefits), другой документ — не смешивать.
- Цифры в тексте ($400 порог, 120 дней) — из CMS, проверены 12.07.2026.
  При обновлении закона (CMS site: cms.gov/medical-bill-rights) — обновить en.json ключи
  gfe.dispute.b1 и gfe.dispute.b2. НЕ менять в es.json до ручной вычитки.
- Слова "coverage"/"covered" в текстах GFE ЗАПРЕЩЕНЫ — см. общее правило.

## ОТКРЫТЫЕ ВОПРОСЫ ПО SLIDING SCALE (из обсуждения 12.07.2026)
- Nominal charge: при ≤100% FPG клиника ВПРАВЕ брать символическую плату ($5–20).
  Поэтому НЕЛЬЗЯ обещать "бесплатно" — только "often free or a small flat fee".
- Слово "coverage"/"covered" в текстах ЗАПРЕЩЕНО: в США читается как страховое покрытие.
  Это не страховка, это скидка от прайса клиники.
- HRSA ≠ бесплатные клиники. NAFC (~1400 free & charitable) — другой механизм,
  без FPG-шкалы. При интеграции NAFC текст в блоке "How does the discount work?"
  придётся переписывать (сейчас там честная оговорка body5 про FQHC-only).
